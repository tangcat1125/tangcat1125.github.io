# 貓老師教學研究企劃｜作品總站

這個儲存庫是 `tangcat1125` 公開作品的導覽首頁：

<https://tangcat1125.github.io/>

首頁已依照帳號下公開儲存庫的入口檔、README 與 GitHub Pages 狀態整理，分成教學研究作品、公開遊戲作品，以及工具與實驗。各作品保留在自己的儲存庫中，總站只負責導覽。

## 本站範圍

- 收錄可直接操作的教學研究、學習遊戲、遊戲創作與互動實驗。
- `taiwan-alien-settlement`、`oceanic-tribe` 與 `canyon_town` 等作品會從總站連到各自的入口。
- 藥學檢測、藥師國考、題庫索引與診斷資料不放進這個總站，並保留在原本的獨立資料夾。

## 本機預覽

在本資料夾啟動靜態伺服器即可預覽：

```powershell
python -m http.server 8011
```

再開啟 <http://localhost:8011/>。
