# 峽谷小鎮（canyon_town）

教室用 HTML5 橫式街遊：學生觀察 NPC／事件架構，讀每季「小鎮報」找出問題，再用政策手牌改寫上季法則，確認政策後看街景日常運行、讀本季結報，問題解決後才進下個月。

## 先讀哪裡

1. `docs/FOLDER_MAP.md` — 資料夾分層（給下一個生成者）
2. `docs/GDD.md` — 遊戲設計與核心迴圈
3. `index.html` — 之後雙擊開啟（file://，不啟動伺服器）

## 硬性約束

- 純靜態：雙擊 `index.html`，禁止 Node／本機 http.server／bat 長駐伺服器
- 圖資全 8-bit；NPC 有男有女
- 畫面橫式軸線（街遊），場景在峽谷小鎮
- 素材宜瘦：教室網約 10 Mbps
